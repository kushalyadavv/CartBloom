## Build

```toml
[extensions.build]
command = "cargo build --target=wasm32-unknown-unknown --release"
path = "target/wasm32-unknown-unknown/release/discount-function.wasm"
watch = [ "src/**/*.rs" ]
```

Untouched scaffold builds in ~29s and produces **68,402 bytes** against the **256 kB (262,144 byte)** cap — **26% consumed**, leaving ~190 kB for the entitlement core.

`Cargo.toml` already optimises for size, which matters given that cap:

```toml
[profile.release]
lto = true
opt-level = "z"
strip = true
```

### The last open assumption, resolved — with a catch

Spec §13 item 3 asked whether market/country is available. **It is:**

```graphql
type Localization {
  country: Country!
  language: Language!
  market: Market! @deprecated(reason: "This `market` field will be removed in a future version of the API.")
}

type Country {
  isoCode: CountryCode!
}
```

**Market targeting is deliverable, but `market` is deprecated and slated for removal.** Target on **`localization.country.isoCode`** (ISO 3166-1 alpha-2), never on `localization.market`. Spec §5's `audience.markets[]` should therefore hold country codes.

This would not have surfaced from the docs — the input schema pages 404 — and building against `market` would have shipped a field Shopify is removing.

### Protected Customer Data — the design still holds, conditionally

`Customer` exposes `email`, `firstName`, `displayName`, and `amountSpent` alongside `hasAnyTag`. **We receive only what the input query requests.**

Since CartBloom queries **only `hasAnyTag`** — which returns a boolean, not customer data — no PII ever reaches the function, and the app stays out of Protected Customer Data entirely (spec §11).

**This is a property of the input query, not of the schema.** Any future change that adds a customer field to `*.graphql` puts the app into PCD Level 1: review, data protection agreements with every merchant, retention policy, encryption at rest. Treat the input query as a compliance boundary, and review changes to it as such.

## Environment caveat

Rust was installed with `--no-modify-path`, so `~/.cargo/bin` is **not** on the interactive shell's `PATH`. The Shopify CLI shells out to `cargo build`, so `shopify app dev` and `shopify app deploy` will fail until this is on `PATH`:

```bash
echo '. "$HOME/.cargo/env"' >> ~/.zshrc && . "$HOME/.cargo/env"
```
